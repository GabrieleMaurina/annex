### Small

Use git diff to review the changes. Ensure the changes are clean, clear, correct, bug free, minimal, and rule compliant. Fix what you can directly, report your findings. Be very careful and meticulous. Do what a top senior software engineer would do. Do not use subagents.

### Large

Use git diff to see all files that have changed. These changes are very extensive. They span many files and many lines of code. Your job is to coordinate an army of subagents to carry out a full code review and audit of the changes. Since the changes are to much to handle for a single agent. You must split the work into a dozen or so smaller units, each targeted by a single agent. Your job is to coordinate them, to follow up with them, and to make decisions about what needs to be fixed. The overall goal should be ensuring the changes are clean, clear, correct, bug free, minimal, and rule compliant. Agents should carry out fixes directly after your approval. Do what a top senior software engineer would do. Make sure the final code is of the highest quality. Compile a short report (<500 words) summarizing findings and fixes.

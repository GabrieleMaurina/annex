Allow additional players to join a full game as spectators, both for games still in the lobby, and for games that are already in progress. Spectators should be able to view the game state, chat with other spectators. The lobby should show current player and separately spectators. If a player leaves while in the lobby, the next spectator in line should be promoted to player status. If a player leaves during an ongoing game, the game should continue without them. Spectators can be banned like players.


When game mode is Team Deathmatch, a new calumn called team should be added. The column contains the team number of the player. The maximum number of teams is equal to the number of players - 1.
